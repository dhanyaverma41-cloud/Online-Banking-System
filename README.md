# Online-Banking-System
An interactive Java-based banking application developed using Swing GUI and Object-Oriented Programming concepts.

— Tools & technologies used: Java, Java Swing, OOP, HashMap
— Developed an online banking system that allows users to register and securely log in, manage their accounts, and perform basic banking operations such as deposit, withdrawal, money transfer, and transaction history. The system provides a simple dashboard where users can view their balance and track their banking activities.
